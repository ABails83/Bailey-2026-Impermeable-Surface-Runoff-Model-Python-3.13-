This repository contains the Python 3.13 code and sample input CSVs to run the impermeable surface runoff model developed in the thesis "Development of a new impermeable surface runoff model for urban catchments considering very shallow flow physics" completed in 2026 at University of Sheffield, UK.

To run single surface model see "Single Surface Runs.md"

To run up to 3 surface model see "Multi-Surface Runs.md"
